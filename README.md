# Limit Order Book Simulator (C++)

## 📖 Overview
This project builds a **synthetic limit order book (LOB)** to simulate order flow in electronic markets.  
It processes incoming buy/sell orders, matches trades, and tracks market dynamics such as **bid/ask prices** and **VWAP execution**.

## ⚙️ Features
- Tick level order book updates  
- Order matching and trade execution  
- Tracking of bid/ask spread  
- VWAP (Volume Weighted Average Price) execution tracking  
- CSV export for market and execution data  

## 🧑‍💻 Technologies
- **C++17** (OOP, STL)  
- Efficient data structures for order matching  
- CSV export for analysis
